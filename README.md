# 🤖 AI-Assisted UI Design: Vercel v0 vs Meta AI

A comparative study exploring how different AI tools approach **UI design, user experience, responsiveness, interaction, and frontend development**.

## 📌 Project Overview

This project compares two AI-assisted interface development approaches:

### 01 — Agentic AI Interface
Built using **Vercel v0**

🔗 **Live Demo:** https://v0.app/trisonics/chat/celestial-tracking-interface-loHKWASaQLO

### 02 — Web Interface
Generated using **Meta AI**

The purpose of this project is to explore how different AI systems interpret similar design requirements and transform them into functional, modern user interfaces.

---

## 🎯 Objective

The primary objective of this project is to conduct a practical comparison of AI-generated UI design based on:

- Visual hierarchy
- Layout and composition
- User experience
- Responsiveness
- Interaction design
- Typography and spacing
- Component organization
- Design consistency
- Human refinement requirements

This project is intended as a **comparative UI/UX experiment**, rather than simply a showcase of AI-generated code.
